# Instructions

Clone this repository to your local machine using Github Desktop (click Code > Open in Github Desktop). Set the Local Path to your `homework` folder in your class folder.

There are two tasks and thus they are separated into two files. You are expected to completed both tasks.

- **Programming + JSON**  Open `HW7_Part1.qmd`. This will involve practicing iteration with map functions and working with JSON files.
- **Navigating the Census API**. Open `HW7_Part2.qmd`. This will involve working directly with the Census API so that you can practice pulling data directly from an API.
